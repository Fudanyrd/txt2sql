# Developer Notes

- LaTex-to-PDF converters: [Overleaf](https://www.overleaf.com/), [Vertopal](https://www.vertopal.com/), [Pandoc](https://github.com/jgm/pandoc)
- Search ACM LaTex Template for building PDF files on your own; save 
  `ACM-Reference-Format.bst` to `src/`.
- Install the "Marp for VS Code" Extension for slide preview
- See AGENTS.md for more
